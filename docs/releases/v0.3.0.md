# podcrates v0.3.0

The third release of podcrates: `pod-proxy`, the dialer of each crate,
from podssh's dial and podnet's proxy chain (milestone M1).

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-proxy` | new: a `Dialer` that implements `pod_core::Dial` from settings (a proxy, MPTCP, the race of addresses with 250 ms between the families, the low-water mark, the write limit); HTTP CONNECT with Basic and Digest; SOCKS5 with `socks5://` (the name resolved here) and `socks5h://` (the name sent); a proxy on a Unix socket (`unix:`) or at a command (`+exec:`, only from a value that the user gave); the proxy variables read through the caller's reader, with the origin of each value and the rules of each consumer (`env::Rules`); the proxy of a tool's configuration; the credentials of a served proxy; the STUN probe; the HTTP client (`Client`: the GET of podssh, the requests and answers of podnet, ECH with the feature `ech`); the cuts of a connection (`Cut`) | podssh, podnet |
| `pod-core` | `Found::more` and `SOURCE_WAIT`: a source of names that has more answers gets 4 s, then the next source is asked | each crate |
| the others | no change | |

## How a consumer takes a crate

```toml
[dependencies]
pod-proxy = { git = "https://github.com/PodUtils/podcrates", tag = "v0.3.0" }
```

Each podcrates dependency of a consumer names the same tag (one source
for cargo). `adoption/CONSUMER/pod-proxy.patch` is the hand-off of each
consumer, at the commit of `adoption/CONSUMER/commit`; the README of
`pod-proxy` has the adoption map of each consumer. After the patch, run
`cargo todo remap Cargo.lock` (and podnet `cargo update -w` in `fuzz/`).

## Breaking

- `socks5://` resolves the name in the dialer and sends the address
  (the rule of curl); `socks5h://` sends the name. podssh sent the name
  for both: its users who need that write `socks5h://`.
- The words of a 407 name Basic and Digest, with the program of
  `Settings::app`.
- `pod_core::Found` has the field `more`.
- A refusal of a proxy with a 5xx status is the class `Unavailable`,
  another refusal `Refused`.

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (ruling Q1).

## Checks

Each crate links into a static binary on each target of the consumers
(the static probe of `ci.yml`). The trials of `adoption.yml` run the tests
of podssh (2,237) and of podnet (784) with `pod-proxy` in place.
