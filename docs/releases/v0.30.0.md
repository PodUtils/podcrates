# podcrates v0.30.0

The thirtieth release of podcrates. For podrunner: the expressions and
the workflow files of GitHub Actions for its local mode (T-251). For
podssh: the MQTT brokers in the runs of a pairing code (T-277,
PodUtils/podssh#210) and the public Syncthing relays on port 443 (T-276,
PodUtils/podssh#209). For podnet: the trial of `pod-relay` (T-026). The
watch `forward-url` proves the URL of each SSH forward relay (T-267).

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-actions-expr` | new: the expressions of GitHub Actions: `Expr::parse`, `evaluate`, `Template`, `Condition` (the implicit `success() &&`), `Value`, `Contexts`; the loose equality and the coercion of the runner; the functions `contains`, `startsWith`, `endsWith`, `format`, `join`, `toJSON`, `fromJSON` and the status functions; `hashFiles` fails by name; the limits of the runner (calls C106, C109) | podrunner |
| `pod-actions-workflow` | new: a workflow file into a typed model (`parse`, `Workflow`, `Job`, `Step`, `Strategy`, `Defaults`; each value with its line and column; an unknown key kept with a `Warning`), the graph of `needs` (`Graph`), and the expansion of jobs (`Run`, `plan`: one concrete job for each cell of a matrix, with `include`, `exclude` and a matrix of `fromJSON`; a skip with its reason). YAML through `saphyr-parser` (call C105); calls C107, C108 | podrunner |
| `pod-relay` | `code::run::Ends` has `brokers` and `resend`; `Ends::new(mailboxes, config)`. Where no mailbox answers, the giver meets at the brokers; a taker that finds no giver at a mailbox looks there too (call C115); the event `relay.code.broker` before the first broker (T-277). The notes of the opener are `&mut (dyn FnMut(&str) + Send)`, so that an open runs in a spawned task (T-026, call C112) | podssh, podnet, podvm |
| `pod-services` | `syncthing-relay` (kind `syncthing-relay`): 25 relays of Syncthing's pool on 443, each with the fact `device-id-relay-ID7`, in the order of the device IDs (T-276, call C104) | podssh |
| `pod-services-watch` | `http-json` takes `url-member` (the members of a URL of an item, T-276); `forward-url` proves the URL with a GET through the forward of the session, with a word of the run (`prove`, T-267) | |

## How a consumer takes it

Each podcrates dependency names the tag `v0.30.0`.

- podrunner: `pod-actions-expr` and `pod-actions-workflow` for its local
  mode (PodUtils/podrunner@T-046). T-280 (their live run against GitHub)
  is open: the rules of calls C107 and C108 are not measured against the
  official runner.
- podssh: `Ends` of `code::run` needs `brokers` and `resend`, or
  `Ends::new`; give the services of the kind `mqtt-broker` as the brokers
  (PodUtils/podssh@T-737). Each closure of notes of an open is `Send`.
  `syncthing-relay` for PodUtils/podssh@T-571.
- podnet: apply `adoption/podnet/pod-relay.patch` of the tag (its trial
  at podnet `98d8a71`): podnet's relay client is glue over `pod-relay`;
  `src/relay_pool.rs` goes. The Done section of T-026 lists the
  behaviours that change and the new pair file (call C111).
- podvm: move the tag; each closure of notes of an open is `Send`.

## Breaking

- `pod_relay::code::run::Ends` has two more fields.
- The notes of `pod_relay::open::open`, `open_on_loopback`,
  `forward_layer::client::Dialer::link` and the roads take `Send`.

## Known defect

- `pod-netstack`: the reactor gives one ACK for the segments of one poll
  (T-197, open).
- `pod-session`: a random failure of one test under load (T-204, open).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
