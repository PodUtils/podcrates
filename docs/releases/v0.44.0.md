# podcrates v0.44.0

The forty-fourth release of podcrates. It carries a fix of security in
`pod-extract` (PodUtils/podvm#354), the defects of podvm's QA report in
`pod-rootfs`, `pod-extract` and `pod-supervise` (#150), the foreground
hold of `pod-supervise` (#148), podrunner's filters of `on:` and calls of
reusable workflows (PodUtils/podrunner#97, #98), and the two parts of the
socket rules of `pod-hold` for podnet (PodUtils/podnet#550).

## Security

- `pod-extract`: the pass of the permissions changed the mode of a
  directory with `fchmodat` on its name, which follows a symlink. A layer
  that left a symlink at the name of a directory of a later layer could
  set the mode of a file outside the tree that the extracting user owns.
  The pass now opens each directory with `O_DIRECTORY | O_NOFOLLOW` and
  changes it through the descriptor (T-597, call C413;
  PodUtils/podvm#354).

## How a consumer takes it

Each podcrates dependency names the tag `v0.44.0`.

- podvm: `pod_supervise::foreground` for a foreground run (start the
  payload, take the hold, reap the payload, then `finish(code)`); the end
  fields of `start` and of a `Dead` record need no work of yours.
- podnet: `Calls::sockets().allow_ping()` for the ping sockets of your
  supervisor, and `.allow_raw()` under `--allow-raw icmp`. Under
  `--allow-raw icmp` your handler now also gets `AF_PACKET`, `AF_XDP` and
  `SOCK_PACKET`: refuse them there.
- podrunner: `Workflow::takes` with a `Trigger`, and `Run::with_called`
  with your source of called workflows.
- podssh: the bump of the tag only.

## Breaking

- `pod-hold`: `Calls::allow_raw()` no longer opens the ping sockets. The
  form of `v0.41.0` is `.allow_raw().allow_ping()`.
- `pod-actions-workflow`: `Outcome` has the variant `Called`; `Instance`
  has the fields `inputs` and `secrets`; `ErrorKind` has new variants.
- `pod-supervise`: `start` refuses while a foreground hold lives in the
  process.

## Known defect

- `pod-extract`: a directory keeps the owner bits after the last layer
  (a `0555` directory of the image is `0755`), and a directory entry over
  a symlink of an earlier layer is not made (T-598, open); the `./` member
  counts as skipped (T-599, open).
- `pod-link`: the listener of the dns, icmp, udp and ws carriers gets no
  `KeyRefused` (T-557, open); an `arq-timeout` ends the whole link (T-514,
  open).
- `pod-relay`: the one form runs over HTTP/1.1 only (T-560, open).
- `pod-session`: a spare link that moves no byte does not back off (T-579,
  open; PodUtils/podssh#242).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
