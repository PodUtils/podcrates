# podcrates v0.8.0

The eighth release of podcrates: `pod-supervise` (the detached payloads of
podvm), `pod-gsr` (the GSRN relay adapter), `pod-broker` (the egress broker of a job), one exit code for each
class of a `pod_core::Failure`, and the JSON log schema.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-supervise` | new: the detached payloads of podvm (`create`, `start`, `kill`, `stop`, `wait`, `remove`, `list`, `logs`, `follow`), the table of records and its lock, the launcher; `stop -t 0` kills at once (podvm #215) (T-060) | podvm (`adoption/podvm/pod-supervise.patch`) |
| `pod-gsr` | new: the GSRN relay adapter of gsocket: `Identity`, `Settings` (from `pod-services` `hackerschoice-gsr`), `open` (async) and `blocking::open`; `Stream::end()` tells a clean end (`End::Clean`) from a cut (`End::Cut`); TLS-SRP on OpenSSL 3.6.3, built from source and linked static (T-086 to T-088; calls C34, C35) | podssh (#164), podnet (#377) |
| `pod-broker` | new: the egress broker of a job: a policy (an allow list, or open egress with fixed denies), one resolve, the upstream chain, `load`, `drop` and the TTL on a control socket, one audit line with no secret (T-099; calls C28 to C32) | podvm `--net broker` later |
| `pod-core` | the classes `Revoked`, `Policy` and `Unsupported`; `Class::ALL` and `Class::exit_code()` on sysexits(3) (T-101); `clock::rfc3339` (T-060) | each tool that exits on a `Failure` |
| `pod-dns` | a name that is not DNS-safe is refused before a resolver sees it, and the JSON form of DoH percent-encodes the name (T-091, #29); `Kept`: one kept connection for each DoH server, 5 s idle, one reconnect, through `Way::kept` (T-125); `Resolver::set_pins`: a pin table that the caller can replace at run time (T-126) | podnet (PodUtils/podnet#413), each client of DoH |
| `pod-proxy` | the `Host` header of an IPv6 literal has its brackets on each port (T-082, #20); `http::exchange_keep` gives the stream back when it can carry another request (T-125) | each client |
| `pod-services` | `tailscale-derp` holds the four missing servers and watches the hosts (T-089, #27); `ajam-relay` watches its hosts and its pool (T-090, #28); `pypi-files`, the file host of PyPI (T-127); `cloudflare-dns` names the TCP probe of the WARP data path (T-097) | podssh, podnet |
| `pod-hostprobe` | on a 32-bit target, `sys::waitid_pidfd` reads `si_status` at the offset of the 32-bit `siginfo_t` (a payload killed by SIGKILL gave 128, not 137), and `sys::ppoll` gives the kernel the 32-bit `timespec` (T-128) | podvm (its i686 and ARM builds) |
| the others | no change | |

`scripts/check-sources.py` reads the default branch of each source
repository (T-085). `schemas/log.v1.schema.json` (the JSON log line) and
`schemas/broker-policy.v1.schema.json` (the policy of `pod-broker`) are new.

## Known defect

- `pod-gsr` on Windows ARM64 (`aarch64-pc-windows-msvc`): a test process of
  `tests/loopback.rs` ends with `STATUS_ACCESS_VIOLATION` after the SRP
  handshake of the vendored OpenSSL (T-131, open). The nightly runs the
  tests of `pod-gsr` on that runner apart, with the output kept. Each other
  target passes. Neither consumer builds `pod-gsr` for Windows ARM64 now.

## How a consumer takes it

Each podcrates dependency names the tag `v0.8.0`. podvm applies
`adoption/podvm/pod-supervise.patch` and runs the lines of
`adoption/podvm/pod-supervise.run`.

## Breaking

- `pod_core::Class` has the variants `Revoked`, `Policy` and `Unsupported`.
  A `match` with no `_` arm adds them.
- `pod_dns::Way` has the public field `kept`. A `Way` built as a struct
  literal adds `kept: None` (the old behaviour: a connection for each
  question).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
