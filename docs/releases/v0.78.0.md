# podcrates v0.78.0

The seventy-eighth release of podcrates. It carries, for the CI of githome
and podrunner, the TLS end of `pod-broker` (placeholder credentials) and
the verifier of `pod-release` as a static command of each release.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-broker` | The TLS end (`Broker::with_tunnel_end(TlsEnd)`): a CA for each job (a P-256 key in the memory of the broker only), written as a bundle that `SSL_CERT_FILE`, `GIT_SSL_CAINFO`, `NODE_EXTRA_CA_CERTS`, `REQUESTS_CA_BUNDLE`, `CURL_CA_BUNDLE` and `AWS_CA_BUNDLE` name (`ca::write_bundle`, `ca::env`); for each host that a credential of the policy names, the broker ends TLS, swaps the placeholder for the value in a header, Basic authentication, a query or a body, and puts the placeholder back in each answer. The policy names a secret, never a value; the host gives the values at the load (`Load::secrets`, `"secrets"` of the control socket). No audit line, log line, answer or error holds a value. Bounds and audit notes: calls C810 to C817 (T-100, githome's G-35 on GitHub #223) | podrunner, podvm |
| `pod-release` | The static binary `pod-release` (feature `cli`): `verify --repo OWNER/REPO --tag TAG [--workflow FILE] [--all] DIR [FILE...]` (or `--identity URI [--issuer URL]`), `sums`, `index`, `man`; exit 64, 66, 69 or 77 with one line `pod-release: CLASS: WHY` (calls C804 to C807). An index must name the caller's signer, and an index that `SHA256SUMS` does not name is refused. `update::Plan::Newer`: a release older than this build, apart from `UpToDate` (T-965, T-971; githome's G-34, PodUtils/podrunner@T-562, PodUtils/podssh#329) | podrunner, podssh, podnet |
| `pod-manual` | `pager::Interrupts` and its `ignore()` are public (call C803, PodUtils/podssh#312); `check::help`, a shared test of a help text (T-969, T-965) | podssh, each command line |
| `pod-testkit` | `tamper::flip`, one changed byte of a fixture (T-965) | each |
| `pod-job` | The `policy` of an offer takes `credentials` (T-100) | podrunner, podvm |

## Schemas

- `broker-policy.v1`: the optional field `credentials` (`placeholder`, `secret`, `hosts`, `in`). An added optional field keeps the id (the owner's ruling "Schema ids").

## Breaking changes

- `pod_broker::Tunnel` has the fields `report` and `vault`: a caller that builds one by its fields names them.
- `pod_release::update::plan` gives `Plan::Newer` where it gave `Plan::UpToDate` for a release older than this build: a `match` with no wildcard gets the arm.
- `pod_release::verify`: a missing file is `NotFound`, not `Unavailable`.

## Release assets

- New: `pod-release-x86_64-unknown-linux-musl` and `pod-release-aarch64-unknown-linux-musl`, in `SHA256SUMS` and in `release-index.json`, and the image `ghcr.io/podutils/pod-release`. `release.yml` checks its own files with `pod-release sums --all` in each run and with `pod-release verify` on the tag.

## Tests and checks

- New plants: `release-index-unread`, `release-named-file-missing`, `broker-tls-answer-not-scrubbed`, `broker-tls-swap-for-any-host`, `broker-tls-sni-not-checked`.
- New fuzz target: `broker_inner`. The fuzz run splits its targets over two jobs (`FUZZ_SHARD`, T-968).
- `scripts/check-strings.py` reads a standard's number after its name in parentheses (`(PKCS) #1`) as no work id.
- The sources of `pod-job`, `pod-manual` and `pod-testkit` agree with podrunner and podssh (T-969); `pod-release` has podssh's `taken` line.
- The tracker test of `pod-wormhole` waits for the `stopped` of an end (T-970).

## How a consumer takes it

Each podcrates dependency names the tag `v0.78.0`; `issue-sync.yml@v0.78.0` takes `podcrates_ref: v0.78.0`.

- podrunner: pin the asset `pod-release-x86_64-unknown-linux-musl` by its SHA-256 for your T-562 (`sums --all dist` in the dry run; `verify --repo PodUtils/podrunner --tag "$GITHUB_REF_NAME" --all dist` on the tag). For G-35, load a job with `Load::secrets` and give the job the bundle of `ca::write_bundle` with the variables of `ca::env`.
- podvm: a broker of `--net broker` can take the TLS end the same way.
- podssh: `Plan::Newer` lets `update::plan` say "this build is newer" (#329); `pager::Interrupts` is public (#312).
- podnet: the tag.
