# podcrates v0.41.0

The forty-first release of podcrates. For podssh: the termios mode of
`pod-term` (T-539, PodUtils/podssh#232), for the tty of `podssh serve`
where no pty opens.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-term` | `termios::Tty`: a line discipline that follows a termios state that the child sets. `Termios` (`sane`, `make_raw`, the Linux values of the flags in `termios::flags`), `When::{Now, Drain, Flush}` for `TCSETS`, `TCSETSW`, `TCSETSF`, `Event::{ToChild, ToUser, Signal, StopOutput, StartOutput}`, `Signal::{Int, Quit, Tstp, Winch}`. `ICANON` with the characters of `c_cc` and `ECHO*`; `ISIG` with `NOFLSH`; `ICRNL`, `INLCR`, `IGNCR`, `ISTRIP`; `IXON` and `IXANY`; `OPOST` with `ONLCR`, `OCRNL`, `ONOCR`, `ONLRET`; the window size with SIGWINCH. The expected bytes of its 55 tests come from a Linux pty (T-539, calls C287 to C289) | podssh |
| `pod-services` | `tox-tcp-relay`: the node at 205.185.115.131 is down; four nodes stay (T-537) | podssh |

## How a consumer takes it

Each podcrates dependency names the tag `v0.41.0`.

- podssh: `pod_term::termios::{Termios, Tty, When}` for the tty of `podssh serve`
  (your T-776, T-111). The caller holds the bytes for the user between
  `StopOutput` and `StartOutput`, and drops the echo that it still holds
  at a `Signal` with `flush` (call C287). The tox relay list has four
  nodes.
- podnet, podvm, podrunner: move the tag.

## Breaking

- None.

## Known defect

- `pod-term`: no test compares `termios::Tty` with a kernel pty (T-540,
  open).
- `pod-link`: an `arq-timeout` ends the whole link, not one stream
  (T-514, open); the ARQ has no congestion window (T-515, open); the
  bytes of a poll listener outside `max_bytes` (T-525, open); the fix of
  `kcp` upstream (T-526, partial).
- `pod-relay`: the client of the HTTP road sends no `POST close` when the
  app drops its stream (T-478, open).
- `pod-netstack`: a stream dropped before its handshake ends finishes the
  handshake later (T-482, open); the reactor gives one ACK for the
  segments of one poll (T-197, open).
- `pod-session`: a random failure of one test under load (T-204, open).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
