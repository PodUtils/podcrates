# podcrates v0.2.0

The second release of podcrates: `pod-tls`, the first crate of the
transport with two sources (milestone M1), and the publish workflow.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-tls` | new: trust and the rustls configurations of a client and of a server with the provider of the caller (`Context`, `Settings`), the system stores of Windows and macOS, the bundles, the TLS groups that servers took, the words of a failed handshake; the pure-Rust provider (feature `pure`) with its RSA verifier (feature `rsa`); Encrypted Client Hello (feature `ech`); podnet's order of roots, its extra roots, the split of the ClientHello (`fragment`) and the notAfter dates of a PEM text | podssh, podnet |
| `pod-core` | `Failure::chain` names a cause once when the text holds it already; `clock::hint` gives a clock before the epoch as it reads | each crate |
| `pod-todo`, `pod-testkit`, `pod-term`, `pod-identity` | no change of the code; publishable (no `publish = false`) | |

## How a consumer takes a crate

```toml
[dependencies]
pod-tls = { git = "https://github.com/PodUtils/podcrates", tag = "v0.2.0", features = ["pure", "rsa", "ech"] }
```

`adoption/CONSUMER/pod-tls.patch` is the hand-off of each consumer, at the
commit of `adoption/CONSUMER/commit`. The README of `pod-tls` has the
adoption map of each consumer: each old path, variable and call site, to
its new form. The trials of the crates that the consumers took in v0.1.0
left `adoption/`.

## Breaking

- `pod_core::Failure::chain`: a cause whose text is in the chain already
  is not named again (before: only a text that ended with it).
- `pod_core::clock::hint`: a clock before the epoch is given as it reads
  (before: as 1970-01-01).
- The words of a failed handshake take the name of the app from the
  caller (`pod_tls::Words`); with podssh's words they are the same as
  before. podnet's clock hint has new words: "certificates are checked
  against this host's clock, which reads ...".

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (ruling Q1): nothing goes
to crates.io.

## Checks

Each crate links into a static binary on each target of the consumers
(the static probe of `ci.yml`). The trials of `adoption.yml` run the tests
of podssh and podnet with `pod-tls` in place.
