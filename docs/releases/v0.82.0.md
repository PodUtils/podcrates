# podcrates v0.82.0

The eighty-second release of podcrates. It carries the post-v0.81.0 fixes
for podvm and podrunner (`pod-extract`, `pod-enter`, `pod-unit`,
`pod-control`), five new crates (`pod-shape`, `pod-cover`, `pod-harness`,
`pod-sidecar`, `pod-offline`), transport and protocol extensions across
`pod-link`, `pod-e2e`, `pod-turn`, `pod-quic`, `pod-warp`, `pod-egress`,
`pod-ws`, `pod-testkit`, `pod-core`, and `pod-manual`, security fixes in
VMess, offline pairing, HTTP/3, and IMAP, and the `url` 2.5.9 update for
RUSTSEC-2026-0592.

## New crates

| Crate | What | Consumers |
| --- | --- | --- |
| `pod-shape` | Traffic padding profiles as TOML data (`file-transfer`, `page-load`, `terminal`, `video-call`), deterministic `Shaper`, `Pacer` with jittered keepalives, `Entropy` control with salted nonce window, and `ShapeReport` (PodUtils/podnet#493) | podnet |
| `pod-cover` | Sans-IO cover site (`Site`, `Sites`), measured cover `Script`, HMAC-SHA-256 `Switch` with replay set, `Mux` volume scheduler, and Ed25519 application-layer `Credential` (PodUtils/podnet#491, PodUtils/podssh#225) | podnet, podssh |
| `pod-harness` | Offline traffic classifiers (`FieldMatcher`, `FlowStats`, `Prefix`), local `Middlebox` simulator, road-by-profile `Matrix` table, relocatable zip `Archive`, claim checker (`check_claims`), and binary `pod-harness` (PodUtils/podnet#501) | podnet |
| `pod-sidecar` | Packet sidecar primitives, deterministic TCP middlebox simulator, genetic search, three-valued disagreement probe, split and tamper with limits, fake TCP framing, and per-flow bond. The feature `sidecar` is off by default (PodUtils/podnet#495) | podnet |
| `pod-offline` | No-network carriers and stores: POSIX raw 8N1 serial line (`serial` feature on by default), AX.25/KISS framing and ARQ, HF modem driver, file spool, signed discovery, delta bundle, capture sink, eight-word single-use pairing with slow hash and claim store, and vector-clock replication log (PodUtils/podnet#499) | podnet |

## Crates

| --- | --- | --- |

| `pod-unit` | Adds `pod_unit::windows::serve`, the Windows Service Control Manager dispatcher for a static program (T-1026) | podrunner, podssh |
| `pod-control` | Wipes each answer that the server drops on a side path (T-1060) | podrunner, podnet |
| `pod-core` | Adds `Class::Permission` (exit code 71) and `Class::Suite` (exit code 78) to `Class::ALL` (13 variants) alongside `chain_of`, `into_source`, `lead`, and `strip_lead` | each |
| `pod-manual` | Adds `Class::Permission` and `Class::Suite` arms in `failure_classes()` | each |
| `pod-link` | Adds optional `ntp`, `smtp`, and `imap` features (off by default), `Rate` and `LimitKind` in `Facts`, bounded IMAP literal reads before allocation (`max_fetch`), and `command_timeout` enforcement (PodUtils/podnet#484) | podnet |
| `pod-e2e` | Adds `Records::seal_with` and padded byte counts for `pod-shape`, opaque fixed-size destination `envelope` (`Destination::seal`/`open`, `Forwarder`, `Pair`), `Inspect`, `Knowledge`, and `record::check_suites` (PodUtils/podnet#493, PodUtils/podnet#496) | podnet, podssh |

| `pod-quic` | Adds `migrate` module for jittered local CID rotation (`Schedule`, `RotatingIds`) and connection migration via `Endpoint::rebind` with session resume (PodUtils/podnet#486) | podnet, podssh |

| `pod-egress` | Adds `coalesce` (3,333-byte first write), `replay` (`ReplayWindow`), `vless::early` 0-RTT offer, Trojan UDP refusal, VMess AEAD chunk count refusal before 16-bit nonce wrap, and vector tests (PodUtils/podssh#224) | podssh, podnet |
| `pod-ws` | Adds `h2_road::shape` (`Shape::browser`, `Shape::firefox`, `Shape::apply` setting `SETTINGS_MAX_CONCURRENT_STREAMS` id 3 and target connection windows 15,728,640 and 12,582,912) and `h2_road::fallback` (PodUtils/podssh#224) | podssh, podnet |
| `pod-testkit` | Adds `vectors` module with SIP004 Shadowsocks, Trojan, and VMess wire conformance vectors (PodUtils/podssh#224) | each |
| `url` (lockfile) | Updates `url` from 2.5.8 to 2.5.9 (`form_urlencoded` 1.2.3) for RUSTSEC-2026-0592 | each |

## Schemas

- `schemas/log.v1.schema.json`: adds `permission` and `suite` to `class` (SHA-256 `b8b586da44389c641916d37446447db081c4806cc53b6c2618296ea52d01da59`).

## Breaking changes

- `pod_core::Class` has two new variants: `Class::Permission` (71) and `Class::Suite` (78). An exhaustive `match` on `Class` needs two arms.
- `pod_egress::vless::Config` adds the field `early: Option<pod_egress::vless::early::Offer>`. Struct literals need the field (or `..Default::default()`).
- `pod_ws::h2_road::Shape::connection_window` holds the connection window target (`15_728_640` for `Shape::browser()`, `12_582_912` for `Shape::firefox()`) rather than the increment; `window_frame()` and `words()` compute the increment above 65,535.
- `pod_extract` refuses GNU sparse files in a layer (T-1087).

## Tests and checks

- Each gate of no blocking call runs in a test binary of its own (T-1082).
- `examples/static-probe` links `pod-cover`, `pod-harness`, `pod-offline`, `pod-shape`, `pod-sidecar` (feature `sidecar`), and `pod-link` features `ntp`, `smtp`, and `imap`.
- `scripts/plants/`: updated context for `e2e-record-phase-unflipped`, `turn-answer-integrity-unchecked`, `turn-coturn-redirect-not-followed`, `turn-downgraded-answer-kept`, `turn-redirect-not-followed`, and `turn-xturn-sha256-unchecked`.

## How a consumer takes it

Each podcrates dependency names the tag `v0.82.0`; `issue-sync.yml@v0.82.0` takes `podcrates_ref: v0.82.0`.

- podrunner: take `v0.82.0` for `pod-extract` ACL support (T-1086), `pod-unit` Windows SCM dispatcher (T-1026), and `pod-control` answer wipe (T-1060).
- podvm: take `v0.82.0` for `pod-extract` (T-1086) and `pod-enter` exit code 126 (T-1080).
- podnet: take `v0.82.0` for `pod-shape`, `pod-cover`, `pod-harness`, `pod-sidecar`, `pod-offline`, `pod-link` (`ntp`, `smtp`, `imap`), `pod-e2e` envelope, `pod-turn` RFC 6062, `pod-quic` migrate, and `pod-warp` H3 shape and provider split.
- podssh: take `v0.82.0` for `pod-cover`, `pod-egress` coalescing/early-data/replay/VMess fix, `pod-ws` HTTP/2 shape (`MAX_CONCURRENT_STREAMS` and target connection window) and fallback, and `pod-testkit` vectors.
