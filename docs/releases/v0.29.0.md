# podcrates v0.29.0

The twenty-ninth release of podcrates. For podnet: the hold of a SYN of
its netns router in `pod-hold` (T-170, PodUtils/podnet#451), a node's
handler that gives each session to a service of the process
(PodUtils/podnet#413), the `Host` of an IPv6 relay and one cache file for
each relay host in `pod-relay`. For podssh: an MQTT meeting point of the
pairing in `pod-wormhole` (PodUtils/podssh#205), the `taken` line of
`pod-relay`, the six plants of the moved code, and a watch of the banner
of each SSH forward relay.

## Crates

| Crate | Change | Consumers |

The live runs: `forward-url` holds for each of the four relays (the zone
of Pinggy is `.run.pinggy-free.link`); `live.yml` pairs through the
public mailboxes and the public MQTT broker on Thursdays and by hand, and
runs the tests of `pod-wormhole` and `pod-relay` against magic-wormhole's
own server each day (`POD_WORMHOLE_TEST_SERVER=required`); `ci.yml` runs
the MQTT tests against Eclipse Mosquitto (`POD_WORMHOLE_TEST_MQTT=required`).

## How a consumer takes it

Each podcrates dependency names the tag `v0.29.0`.

- podnet: apply `adoption/podnet/pod-hold-syn.patch` of the tag (its
  trial at podnet `a7350b2` passed in `adoption.yml`): podnet's netns
  router takes `pod_hold::syn_hold`, and its dial, rules, flow log and DNS
  stay in podnet as a `Dial`. The T-170 Done section names four defects
  of the router at `a7350b2` that the crate does not have.
- podssh: wire the MQTT meeting point (PodUtils/podssh@T-737) where no
  mailbox answers. The cache files of the relay token and the pool have
  new names: one more mint and one more read of a pool after the take.
- podvm and podrunner move the tag.

## Breaking

- `pod_wormhole::Failed::Unreachable` has new words.
- `pod-relay`: the cache file names of the token, the pool and the offers
  change; the old files are not read.
- `pod-services`: `node-xhttp-78-17-39-129` is gone.

## Known defect

- `pod-netstack`: the reactor gives one ACK for the segments of one poll
  (T-197, open).
- `pod-session`: a random failure of one test under load (T-204, open).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
- `forward-url` takes the first URL that the rule accepts; a request
  through the tunnel does not prove it yet (T-267, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
