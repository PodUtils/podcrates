# podcrates v0.1.0

The first release of podcrates: the foundation (milestone M0) and the
first crates of the transport (milestone M1).

## Crates

| Crate | What | Consumers |
| --- | --- | --- |
| `pod-todo` | the checker of a work record in `TODO/`, with the facts of each repository in `TODO/todo.toml` | podssh, podnet, podcrates |
| `pod-core` | the `Dial`, `Resolve` and `Datagrams` traits, the `Failure` with its stage and class, events and the observer, `Metered`, backoff, the clock, safe text, name checks, the entropy source, the private files and the places of an app (`files`) | each crate |
| `pod-testkit` | `need_loopback!`, `need_localhost!`; the terminal oracle `screen::Screen` (feature `screen`) | the tests of each crate and consumer |
| `pod-term` | the line discipline of a terminal and the grammar of its output | podssh, podvm |
| `pod-identity` | the Ed25519 identity of a node, its key files, the pins of node keys and the allowlist | podssh, podnet |

## How a consumer takes a crate

```toml
[dependencies]
pod-todo = { git = "https://github.com/PodUtils/podcrates", tag = "v0.1.0" }
```

Add `https://github.com/PodUtils/podcrates` to `allow-git` of `deny.toml`.
The README of each crate has its adoption map. `adoption/CONSUMER/` has
the patch of each trial that passed:

| Consumer | Crates |
| --- | --- |
| podssh | `pod-todo`, `pod-term`, `pod-identity` |
| podnet | `pod-todo` |

A patch is the hand-off to the consumer session: apply it at the commit
of `adoption/CONSUMER/commit`, then change the git source to the tag.

## Breaking

None: the first release.

## Checks

Each crate links into a static binary on each target of the consumers
(the static probe of `ci.yml`), its tests pass on Linux each push and on
macOS, Windows and the other Linux targets each night. The trials of
`adoption.yml` run the tests of each consumer with the crates in place.
