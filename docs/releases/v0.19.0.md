# podcrates v0.19.0

The nineteenth release of podcrates. For podvm: the library directories
of the userland rung come from the image (its `/usr/local/lib` and its
loader configuration), each resolved inside the image, and the loader
plan says when to give `--inhibit-cache`; the tests of `pod-enter` under a
bare qemu-user. For podrunner: a raw byte in the path of a plain request
is refused by `pod-broker`. For podssh: the words of a mailbox end with no
space. `pod-services-watch` speaks VLESS over XHTTP; `pod-oci` has a live
test against ECR Public.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-enter` | `userland::lib_dirs` gives the loader's directory, the standard ones with `/usr/local/lib`, `/usr/local/lib64` and their multiarch forms, then each directory of the image's `/etc/ld.so.conf` (with `include` globs) or `/etc/ld-musl-ARCH.path` (`userland::ldconf`, with bounds); each directory resolves inside the image through the table, so a `/lib` that links to the absolute `/usr/lib` no longer names the host's `/usr/lib`. `LoaderPlan::inhibit_cache` and `takes_inhibit_cache`: the loader is glibc 2.16 or later (T-182, PodUtils/podvm#247) | podvm (PodUtils/podvm@T-1719) |
| `pod-hostprobe` | `interp::detect` finds a bare `qemu-<arch> ./binary` by the name of the process (`/proc/self/comm`), which qemu-user does not emulate; `interp::qemu_comm` (T-149) | podvm (its probe), `pod-enter` (its tests) |
| `pod-broker` | `target::normal_path` refuses a raw byte outside `0x21..0x7f`: it read a raw UTF-8 character as two Latin-1 characters and passed a raw control byte (T-183, a crash of `fuzz.yml`) | podrunner, podvm (`--net broker`) |
| `pod-wormhole` | `message::words` ends with no space after its cut (T-184, a crash of `fuzz.yml`) | podssh |
| `pod-services-watch` | `proxy-banner` speaks VLESS over XHTTP in the `packet-up` mode, over HTTP/1.1 and HTTP/2, with TLS and ALPN (Xray-core at `c43ee98`); a share link is percent-decoded; a VLESS link with `flow` or `encryption` is skipped (T-152; call C52) | `services.yml` |
| `pod-oci` | `tests/live.rs`: a pull of the pinned guest userland of `ecr-public-registry` for two platforms in `live.yml`; a 429 is a skip (T-142) | none |

## How a consumer takes it

Each podcrates dependency names the tag `v0.19.0`. podvm gives
`--inhibit-cache` to the loader where `LoaderPlan::inhibit_cache` is true.

## Breaking

- `pod_enter::userland::LoaderPlan` has the field `inhibit_cache`: a
  struct literal names it.
- `pod_broker::target::normal_path` and `parse_absolute` refuse a path
  with a raw byte that is not visible ASCII; its escape (`%D1%87`) passes
  as before.
- `pod-enter`: each library directory is a resolved host path; where the
  image's `/lib` is a link, `lib_dirs` names its target, not the link.

## Known defect

- `pod-gsr` on Windows ARM64: a test process ends with
  `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
