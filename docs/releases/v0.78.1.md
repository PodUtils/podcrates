# podcrates v0.78.1

The seventy-eighth release of podcrates, as `v0.78.1`. It carries each
change of `v0.78.0` (`docs/releases/v0.78.0.md`) and the fix of
`release.yml` that the release of `v0.78.0` needed. The tag `v0.78.0`
exists and has no GitHub release (call C818): take `v0.78.1`.

## Changes after v0.78.0

| Part | Change | Consumers |
| --- | --- | --- |
| `release.yml` | Each step that makes a changed copy of the release has a path of its own (`changed-index`, `changed-sums`, `changed-verify`) and removes it before and after its check. The run on the tag `v0.78.0` stopped after the signature, because two steps shared `$RUNNER_TEMP/changed` (T-974). | none |

## The content of v0.78.0

Read `docs/releases/v0.78.0.md`: the TLS end of `pod-broker` (T-100), the static command `pod-release` (T-965), `update::Plan::Newer` (T-971), `pod_manual::pager::Interrupts` public, the field `credentials` of `broker-policy.v1`, and its breaking changes.

Each podcrates dependency names the tag `v0.78.1`; `issue-sync.yml@v0.78.1` takes `podcrates_ref: v0.78.1`. The steps of `docs/releases/v0.78.0.md` apply as they are, with `v0.78.1` in place of `v0.78.0`.
