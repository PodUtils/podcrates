# podcrates v0.14.0

The fourteenth release of podcrates: `pod-quic`, one QUIC stack on noq for
podssh and podnet; `pod-services-watch`, the daily watches of the data of
`pod-services`; the services `serveo`, `ssh-j` and `croc`; the timed tests
under an emulator.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-quic` | new: the QUIC endpoint, the probe and QUIC over datagrams, on noq 1.4 (T-019; calls C43, C44). `Settings`, `keys::{ResetKey, TokenKey}` (HMAC-SHA-256 in pure Rust from the caller's entropy), `endpoint::{config, server_config, on_socket, bind, system, server, over}`, `connect::{tls, client_config, connect, handshake}`, `probe::{packet, answers, probe}`, `queued::QueuedDatagrams` over a `Link` (podnet's WARP socket), `socket::DatagramSocket` (noq's socket over any `Datagrams`); each error a `pod_core::Failure`; `noq` re-exported. The caller gives the TLS provider. Fixed against the sources: a second sender on a full datagram queue lost its wake-up (one waker for each sender now); the client's own verifier is rustls's root verifier. The fuzz target `quic_probe_answer` | podssh (`adoption/podssh/pod-quic.patch`), podnet (`adoption/podnet/pod-quic.patch`: no quinn is left in podnet) |
| `pod-services-watch` | new, `publish = false`: one check for each of the 24 watch kinds of the data, each with an offline test and a plant; the runner and `services.yml` (each day, and by hand) (T-050; call C42) | podcrates |
| `pod-services` | the services `serveo` and `ssh-j` (T-153, PodUtils/podssh#182) and `croc` (T-156, PodUtils/podssh#183); the watch of `croc` upgrades the bridge to a relay (T-158); the fixes of the data from the first runs of the watches (T-050) | podssh |
| `pod-testkit` | `host::emulated()` and `host::scaled(Duration)`: one bound of a timed test, five times longer under an emulator (T-154); the stand-ins of HTTP, raw TCP and UDP (feature `stand`, T-050) | the tests of each crate |
| the others | the bounds of their timed tests (T-154); no change of an API | |

## How a consumer takes it

Each podcrates dependency names the tag `v0.14.0`. podssh applies
`adoption/podssh/pod-quic.patch` (made on podssh `c5636c9`); podnet applies
`adoption/podnet/pod-quic.patch` (made on podnet `5465007`). Each runs the
lines of its `.run`. `crates/pod-quic/README.md`, "Adoption map", lists what
stays in each consumer. podvm needs no code change.

## Breaking

- None in a crate that a consumer takes now. podnet moves from quinn to
  noq with the patch.

## Known defect

- `pod-gsr` on Windows ARM64: a test process ends with
  `STATUS_ACCESS_VIOLATION` (T-131, open).
- Three tests of `pod-enter` fail under qemu-user only (T-149, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
