# podcrates v0.6.0

The sixth release of podcrates: `pod-hostprobe`, the first crate of podvm
(milestone M6), and the fixes that the trials of podvm found in
`pod-proxy`.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-hostprobe` | new, from podvm's `podvm-probe` (T-055): the host probes, each in a disposable child, with the errno recorded and "could not run" as a third state; the selection of a mode with its controls; the raw system calls (`sys`); the identity, the interpreter, the mounts, `binfmt`, the writable places, the space and the exec probes. Linux only (an empty crate elsewhere); `Settings` for the names of the consumer; no environment read | podvm (its take is the next trial) |
| `pod-hostprobe` | `sys::statfs` calls `statfs64` with the size of its buffer on a 32-bit target (T-072) | podvm |
| `pod-proxy` | a request of plain `http://` takes `http_proxy`, then `HTTP_PROXY`, then `ALL_PROXY`, then the proxy of `https://` (`Rules::http_proxy_vars`; curl's list is `HTTP_PROXY_VARS_LOWER`) (T-075) | podvm |
| `pod-proxy` | a refused dial of an address names the address once (T-074) | each |
| `pod-dns` | a debug line `doh answered` names the server that answered (T-073) | podnet |
| `pod-core` | `Dial::dial_http` (its default is `dial`); `Stage::Host` (T-055, T-075) | each |
| `pod-testkit` | `need_userns!`, `need_tool!` | |
| the others | no change | |

## How a consumer takes it

Each podcrates dependency names the tag `v0.6.0`.

## Breaking

- `pod_proxy::env::Rules` has the field `http_proxy_vars`: a `Rules`
  built as a struct literal adds it (podnet: `&pod_proxy::HTTP_PROXY_VARS_UPPER_FIRST`).
- `pod_core::Stage` has the variant `Host`: a `match` with no `_` arm adds it.
- `pod_proxy::ProxyChoice::FromEnvironment` holds a larger `Environment`.

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (ruling Q1).
